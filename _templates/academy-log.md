**부산** — 서면점·연산점은 역에서 얼마나 → 퇴근 후 몇 시까지 → 토요일 4시간만으로 가능한지 → 과정은 취업까지 어떤 순서 → 비용과 교육지원 → 직장인 FAQ → 핵심 정리 → 출처

**송파구** — 생활권(노선)별 가까운 지점 → 천호점·강남점 같은 점·다른 점 → 미용도구 따로 사야 하는지 → 주부 평일 낮 수업 → 교육비·지원 → FAQ → 핵심 정리 → 참고자료
